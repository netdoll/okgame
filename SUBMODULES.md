# Submodule Dashboard

This dashboard lists all submodules used in the project, their paths, and upstream URLs.

## Project Structure Overview
*   **src/**: Main application source code.
*   **lib/**: External libraries and submodules.
*   **resources/**: Assets and presets (including visualizer presets).
*   **cmake/**: CMake modules.
