# IDEAS: okgame (C++)

## 1. Feature Improvements
- **Visualizer Gallery:** A dedicated mode to browse and customize projectM presets with game integration.
- **Steam Deck Optimization:** Fine-tune input and UI for the Steam Deck form factor.
- **Advanced Lua API:** Expose more engine internals to Lua for deeper modding support.

## 2. Refactoring & Performance
- **Vulkan Backend:** Research a Vulkan rendering backend for future-proofing and performance.
- **Task Parallelism:** Use a task-based system for offloading non-rendering work (network, physics) to multiple cores.

## 3. Project Pivot
- **AI Training Ground:** Use the deterministic puzzle engine as an environment for training RL agents.
- **Retro-Engine:** Decouple the engine logic to be a generic retro-game engine for other 2D projects.
